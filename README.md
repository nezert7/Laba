# Приложение Notes Library
:books: Терял тетрадь с лекциями прямо перед сессией? Не мог разобрать собственный почерк после лекции по матанализу?
Тогда наше приложение точно поможет тебе в учебе - мы предлагаем простой интерфейс, позволяющий пользоваться коспектами с занятий.
## Интеллект, организованный в конспекты.
:bookmark_tabs: Студенты активно пользуются записями лекций, обмениваются конспектами и учат материал перед сессией. Любой студент может заболеть, 
отстать по программе или просто не успеть записать важную мысль из-за скорости речи преподавателя. А пропуск даже одной темы может создать «снежный ком» непонимания.
> [!TIP]
> Мы создали приложение, которое страхует от пробелов в знаниях. Это гарантия, что ни одна важная лекция не будет пропущена.
## Авторизация
:accessibility: Каждый пользователь проходит регистрацию - будьте уверены, что Ваши конспекты сохранятся надолго и никуда не пропадут. 
## Функционал
:eye_speech_bubble: В Notes Library у пользователей есть возможность добавлять конспекты и просматривать их. Сортировать по предметам и сохранять на устройстве. Неактуальные
файлы всегда можно удалить.
Подобное приложение крайне актуально для студентов, особенно в период завалов на учебе. 
Для оптимизации учебного процесса пользователям доступны:
- выбор даты лекции
- выбор предмета
- сортировка по предметам
- сохранение и удаление файлов
